# 💚 ConectaVzla — Página Oficial

> **Chatea sin dar tu número.** El mensajero privado y sencillo que no te pide nada: sin número telefónico, sin correo y sin vender tus datos.

## ✨ ¿Qué es ConectaVzla?

ConectaVzla es una aplicación de mensajería instantánea **hecha en Venezuela** 🇻🇪, diseñada para conectar a las personas que importan **sin entregar tus datos personales a nadie**.

Esta página es la **landing oficial** del proyecto: su carta de presentación al mundo.

## 🚀 Características destacadas

- **Cuenta en 10 segundos** → solo usuario y contraseña
- **Interfaz familiar** → tan fácil como tu app de chat favorita
- **PWA instalable** → funciona en Android, iPhone y PC sin descargar nada pesado
- **Súper ligera** → ideal para cualquier teléfono
- **Hecha con amor** → nació para conectar familias venezolanas

---

## 🛠️ Tecnologías

### Esta landing page
- HTML5 semántico
- CSS3 puro (sin frameworks)
- Diseño 100% responsive
- Hospedada en **GitHub Pages**

### La aplicación ConectaVzla
- JavaScript Vanilla
- [Supabase](https://supabase.com) (Auth, Realtime, Storage, PostgreSQL)
- PWA (Service Worker + Manifest)
- Web APIs (MediaRecorder, Canvas)

📂 **Repositorio de la app:** [conectavzla](https://github.com/TU-USUARIO/conectavzla)
